# Prayer Times

A React app that shows the five daily prayer times (plus sunrise) for any city and date, using the [Aladhan API](https://aladhan.com/prayer-times-api).

## Features
- Look up prayer times by city name
- Check times for any date, not just today
- Loading and error states, with retry on failure

## Tech stack
- React (hooks)
- Axios
- Aladhan API

## Running locally
1. Clone the repo
2. `npm install`
3. `npm run dev`

## Notes
Built as a learning project to practice consuming an external API with React state and effects.
